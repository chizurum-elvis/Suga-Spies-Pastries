# Storefront image sources

The homepage uses the licensed Pexels photography below. On August 29, 2026, the owner approved continuing to use these selected images on the storefront and asked for the temporary “reference photography” labels to be removed from the customer interface.

These are still stock photographs rather than photographs of finished Suga & Spies orders. Before production launch, the owner must confirm that each photograph materially represents the product customers will receive, including its form, portion, garnish, and packaging. Replacement is required only where that product-representation review fails or the applicable image licence no longer permits use.
